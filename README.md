# Nebulark Landing Page

Integrated Nebulark landing page with Next.js corporate blog.

## Features

- Modern React with Next.js 15
- TSParticles integration for interactive backgrounds
- Blog functionality with Wisp CMS
- Responsive design with Bootstrap
- SEO optimized

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project is configured for Vercel deployment with proper Next.js settings.
